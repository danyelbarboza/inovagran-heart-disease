# InovaGRAN — Classificação de Doenças Cardíacas

Este repositório reúne os códigos, experimentos e resultados desenvolvidos no âmbito do projeto de Iniciação Científica **InovaGRAN**, dedicado à aplicação de redes neurais artificiais, especialmente Multilayer Perceptron (MLP), na classificação de doenças cardíacas. A pesquisa utiliza a base *Heart Disease*, disponibilizada pelo UCI Machine Learning Repository, para investigar técnicas de pré-processamento, seleção de atributos e configuração de modelos de aprendizado de máquina.

O repositório tem como objetivo centralizar o desenvolvimento colaborativo, facilitar a reprodução dos experimentos e documentar a evolução metodológica da pesquisa. Os códigos e resultados são organizados de modo a permitir o acompanhamento das diferentes abordagens experimentais, incluindo estratégias de treinamento, validação cruzada e avaliação do desempenho preditivo.
